# Scrada Cadeaubonnen

This repository contains an educational project developed during the first year of university. 

The project is a backend application for managing gift certificates (Cadeaubonnen). It features an integration with the Stripe payment system to process transactions.

---

## Technologies

* **Language:** C#
* **Framework:** ASP.NET Core
* **Database:** Microsoft SQL Server
* **Integrations:** Stripe API (payments and webhooks)
